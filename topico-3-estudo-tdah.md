# Tópico 3 — versão para estudar com TDAH

> Formato: blocos curtos, não parágrafos longos. Leia um bloco, respira, próximo bloco.

## 🎯 Resumo em 3 frases (leia isso primeiro, sempre)

- **Custos** = quanto a produção gasta
- **Fluxo de caixa** = quando esse dinheiro entra e sai
- **Crédito rural** = de onde vem grana quando falta

Se esquecer tudo o resto, lembra só dessas 3 linhas.

---

## 1️⃣ Controle de custos

**Essência:** saber quanto a safra custou de verdade.

Quem faz esse levantamento: **Conab**, desde 1976.

Dois tipos de custo:

- 🔒 **Fixo** — existe mesmo sem produzir nada
  - máquina depreciando
  - terra (custo de oportunidade)
  - funcionário fixo
- 🔁 **Variável** — muda com o tanto que planta
  - semente, adubo, defensivo
  - combustível
  - diarista

**Por que importa:** numa safra ruim, custo fixo não some. Saber separar ajuda a decidir onde cortar.

**Frase pronta pra falar:** "Não dá pra saber se deu lucro sem saber quanto custou."

---

## 2️⃣ Fluxo de caixa

**Essência:** não é lucro. É *quando* o dinheiro entra e sai.

Ordem na agropecuária:

1. gasta primeiro (plantio)
2. só recebe depois (venda da colheita)
3. logo → caixa negativo por um tempo é **normal**, não é erro

**Boa prática:** comparar todo mês o que foi **planejado** x o que **realmente aconteceu**.

**Serve pra quê:** avisar com antecedência se vai faltar dinheiro em algum mês.

---

## 3️⃣ Crédito rural

**Essência:** dinheiro emprestado tem "sabor" — cada tipo serve pra uma coisa.

As 4 finalidades (Banco Central):

| Tipo | Serve pra |
|---|---|
| **Custeio** | pagar a safra em andamento |
| **Investimento** | máquina, estrutura |
| **Comercialização** | vender depois, com preço melhor |
| **Industrialização** | processar o produto |

De onde vem o dinheiro: banco é **obrigado** a destinar parte dos depósitos (exigibilidade) + poupança rural + recursos livres.

Quem pode pegar: pessoa física, jurídica, cooperativa, associação — regras no **MCR** (Manual de Crédito Rural).

Dois nomes pra guardar:

- **Pronaf** → crédito fácil, só pra agricultura **familiar**
- **Proagro** → não é crédito, é **seguro**. Se perder a safra por clima ruim, ele quita o custeio.

---

## 🔥 Cola rápida antes de apresentar

- Custo → CONAB → fixo x variável
- Caixa → quando entra/sai, não quanto sobra
- Crédito → custeio / investimento / comercialização / industrialização
- Pronaf = família · Proagro = seguro contra clima

## ❓ Se perguntarem

- *"Pronaf é pra qualquer produtor?"* → Não, só agricultura familiar.
- *"Proagro é obrigatório?"* → Não, é contratado à parte.
- *"Juros mudam por tipo de crédito?"* → Sim, tá no MCR / Plano Safra.
